# Миграция e-arhiv.vko.gov.kz -> вариант A (a-gos)

Источник данных: `docs/research/current-site/` (INVENTORY.md, content/*.json, raw/). Дизайн старого сайта (коричневый, золото, курсив, текстуры) не переносился: только данные и структура меню. Все страницы собраны из компонентов style.css варианта A (TNA, зелёный акцент, плоско, моно-шифры). Тексты ru и kk переключаются кнопкой KZ/RU; для документов, существующих на одном языке, показан он же. Файлы документов (docx, pdf, xlsb) ведут на старый сайт, локально не копировались (343 файла, 139 МБ).

Генератор страниц: скрипты в /tmp/cm9gen (не входят в репозиторий); результат лежит в этой папке.
