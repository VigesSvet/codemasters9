# Бриф: варианты макета главной + карточки дела (v2, на фактах реверса)

Проект: хакатон Code Masters 9.0 — новый сайт Госархива ВКО (Казахстан), репо ~/work/codemasters9. ТЗ: docs/tz/TZ.txt.
Прошлые макеты (docs/mockups) пользователь назвал AI-слопом — НЕ смотри на них и не повторяй их идей.
База: живой реверс 8 топ-сайтов в docs/research/reverse/<site>/ (notes.md, tokens.json, shots/) и сводка docs/research/reverse/SYNTHESIS.md (дизайн-система ВКО v1, CSS-переменные в §3.7, экраны в §5).

## Главное правило
Собирай 1в1 по РЕФЕРЕНС-скринам своего варианта: та же сетка, пропорции, размеры, отступы, иерархия, плотность — только контент ВКО и шрифты/цвета из своего варианта. Открой референс-скрины (Read) и замеряй по ним; цифры бери из notes.md/tokens.json референса. Никаких «креативных» идей сверху: ни градиентов, ни стеклянных карточек, ни скруглённых плашек с тенями, ни эмодзи, ни декоративных блобов, ни «AI-иконок». Если у референса так нет — у нас тоже нет.

## Контент (реальный, по-русски, переключатель KZ/RU/EN в шапке)
- Госархив ВКО: Усть-Каменогорск (Өскемен) + филиалы (Семей, Риддер, Зыряновск/Алтай, Аягоз, Зайсан, Шемонаиха и др. — сверь с docs/research/current-site.md / current-site-data.json).
- Разделы ТЗ: Каталог (фонд → опись → дело), Цифровая история региона, Онлайн-выставки, Филиалы на карте, ИИ-помощник, Об архиве, Отзывы и предложения. Сайт информационный — без заявок/заказов/оплаты.
- Примеры фондов/дел: правдоподобные, с шифрами вида «Ф. 1-П, оп. 1, д. 245», без порочащих реальных лиц.
- Фото: реальные исторические фото региона с Wikimedia Commons (Семипалатинск/Усть-Каменогорск XIX–XX вв., public domain), скачай в папку варианта `img/` (curl, пауза между запросами), подпиши источник. Никаких стоковых/сгенерированных картинок.

## Что сделать
1. `docs/mockups-v2/<variant>/index.html` — главная (статичный HTML+CSS, можно чуть JS для темы/языка), адаптив.
2. `docs/mockups-v2/<variant>/delo.html` — карточка дела с иерархией фонд→опись→дело и превью скана (по паттерну из SYNTHESIS §2.3 в стилистике своего варианта).
3. Скриншоты через headless Chrome (`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --screenshot=... --window-size=1440,900 --hide-scrollbars file://...`; для полной страницы — CDP на своём порту): `home-desktop.png` (1440 первый экран), `home-desktop-full.png`, `home-mobile.png` (390×844), `delo-desktop.png`.
4. Сам сравни свои скрины с референсными бок о бок (Read обоих) и поправь расхождения хотя бы 1 итерацию. Проверь, что казахские буквы (ә ғ қ ң ө ұ ү һ і) рендерятся нужным шрифтом.

Пиши только в свою папку docs/mockups-v2/<variant>/. Не коммить. В финальном ответе — 5 строк: что взято у референса, пути к png, что не получилось.
