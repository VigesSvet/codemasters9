# Аудит безопасности codemasters9 @ 0b1a23b (12.11.2026)

Аудит по коду(FTS5 проверен запуском на in-memory SQLite), исправления - отдельной веткой с тестами на каждую находку. Пути относительно корня репозитория. Статус исправлений - в `docs/SECURITY.md`.

## A. Находки (по убыванию серьёзности)

**SEC-01 · Высокая · Публичный поиск падает в 500 на спецсимволах FTS5.**
`backend/app/search.py:20-29` (`_fts_expr`), вызовы `:221,:233,:240`; `routers/catalog.py:33-79`. `q=ф.1`(обычный шифр), `"`, `a(b`, `x*`, `col:x`, `o'neil`, `привет!` уходят в MATCH как есть → `sqlite3.OperationalError` → 500; 11 из 17 тестовых строк дают ошибку. Ретривер ИИ безопасен(берёт только `[0-9A-Za-zА-Яа-яЁё]+`).
Правка: токены `re.findall(r"\w+", norm(variant))` в кавычках `f'"{t}"*'`; `q` ≤ 200 символов, ≤ 16 токенов; `OperationalError` → фолбэк на LIKE.
Тест: параметризованный `test_search_special_chars_no_500`, `test_search_quoted_token_matches`.

**SEC-02 · Средняя · Нет лимита тела запроса; загрузка читает файл целиком до проверки размера.**
`routers/admin.py:364-366`, `routers/imports.py:50-52`; в `security.py` лимита `Content-Length` нет. Тело 2 ГБ → память процесса.
Правка: middleware `Content-Length > 25 МБ` → 413 JSON; `file.file.read(MAX + 1)`; `max_length` в `LoginRequest`(username 64, password 256) и `AiRequest.question`(500).
Тест: `test_body_too_large_413`, `test_upload_over_limit_413`.

**SEC-03 · Средняя · XLSX: zip-бомба и 500 на битом файле.**
`importer.py:100-119` копит все строки до проверки `MAX_ROWS`(`:200`); `:122-126` - `BadZipFile`/`KeyError` не перехватываются.
Правка: стоп на `MAX_ROWS + 1`, колонок ≤ 64, `load_workbook` в `try` → `ImporterError` → 422.
Тест: `test_import_xlsx_too_many_rows_422`, `test_import_bad_xlsx_422`.

**SEC-04 · Средняя · IDOR: применение чужого импорта.**
`importer.py:292-306` не сверяет `job.user_id`; `routers/imports.py:61-73`. Редактор B применяет preview редактора A. Противоречит п. 3.5 дополнений(права на конкретный объект).
Правка: не admin и `job.user_id != user.id` → 403 + audit denied.
Тест: `test_import_apply_other_user_403`.

**SEC-05 · Средняя · Лимит входов: блокировка за прокси, обход по IP, перечисление пользователей по таймингу.**
`routers/auth.py:43-53`, `Dockerfile:22`. За nginx у всех один `client.host` → 5 ошибок блокируют admin для всех; ротация IP не ограничена; на несуществующий логин ответ быстрее(нет scrypt).
Правка: второй счётчик по IP(30 неудач / 10 мин → 429); для неизвестного логина - `verify_password` против фиктивного хеша; чистка старых `login_attempts`; в документации `FORWARDED_ALLOW_IPS`.
Тест: `test_login_ip_limit_across_usernames`, `test_login_unknown_user_401_same_message`.

**SEC-06 · Средняя · Утечка существования файла неопубликованной единицы.**
`routers/catalog.py:288-289`: черновик → 403 `reason: unpublished`, а несуществующий → 404. Перебором видно, что файл есть.
Правка: неопубликованное → 404 без `reason`.
Тест: `test_download_unpublished_404`.

**SEC-07 · Средняя · CSV-инъекция в `export.csv`.**
`routers/admin.py:574-594`. Заголовок `=HYPERLINK(...)` выполнится в Excel модератора.
Правка: `_csv_safe` - префикс `'` для значений с `= + - @ \t \r`.
Тест: `test_export_csv_neutralizes_formulas`.

**SEC-08 · Средняя · Общий демо-пароль `Demo-2026!` у всех ролей, смены пароля нет.**
`backend/seed/load.py:22,43-44`, `.env.example`, `docker-compose.yml`.
Правка: флаг `password_is_default` в `/login` и `/me` + баннер в админке; предупреждение в seed без `SEED_PASSWORD`; при наличии времени `POST /api/auth/password`(мин. 10 символов, сброс других сессий, audit).

**SEC-09 · Низкая · scrypt ниже рекомендаций OWASP** - `security.py:18-20`(N=2^14, r=8, p=1). Правка: `p=5`(16 МиБ); старые хеши проверяются, параметры хранятся в строке хеша.

**SEC-10 · Низкая · CSP `script-src 'unsafe-inline'`, нет HSTS/COOP/CORP** - `security.py:34-35,194-202`. Сейчас: HSTS при `COOKIE_SECURE`, COOP/CORP `same-origin`. Nonce для inline-скриптов - следующий этап.

**SEC-11 · Низкая · Открыты `/docs`, `/redoc`, `/openapi.json`** - `main.py:27`. Правка: выключены, если не `API_DOCS=true`.

**SEC-12 · Низкая · Неограниченные `per_page`/отрицательный `page` в админ-списках** - `routers/admin.py:110-144,502-535`. Правка: `page ≥ 1`, `1 ≤ per_page ≤ 100`.

**SEC-13 · Низкая · branch_admin читает черновики, версии и файлы всех филиалов** - `routers/admin.py:110-144,233-240,326-345,434-452`. Правка: фильтр по `branch_id`, чужое → 404.

**SEC-14 · Низкая · CI без `permissions`, без аудита зависимостей, версии не зафиксированы** - `.github/workflows/ci.yml`, `requirements.txt`. Правка: `permissions: contents: read`, `pip-audit`, пины `==`.

**SEC-15 · Низкая(принятый риск) · HTML новостей без санитайзера** - `web/novost.html:33,54`. Источник - только seed из старого сайта, в нём нет `<script`, `on*=`, `javascript:`, `<iframe`; редактирования новостей нет. План: allowlist-санитайзер при сохранении.

**SEC-16 · Низкая · Доверие заголовку Host в sitemap/robots** - `routers/seo.py:31,49`. План: `TrustedHostMiddleware` или `BASE_URL`.

**SEC-17 · Низкая · Сессии без абсолютного срока и очистки, cookie не продлевается** - `security.py:97-134`, `auth.py:65-74`. План: лимит 12 ч, чистка, продление cookie.

**SEC-18 · Низкая · Нетипизированные тела админ-запросов → 500** - `routers/admin.py:244-292,468-496,615-656`. План: pydantic-модели.

**SEC-19 · Инфо · Фонды видны независимо от опубликованных единиц** - `importer.py:265-276`, `catalog.py:199-264`. План: показывать фонд, только если есть опубликованное.

**SEC-20 · Инфо · Внешний ИИ без системного промпта** - `ai/providers.py:31-40`. Наружу уходят только вопрос и заголовки открытых единиц; по умолчанию `local`. План: system-промпт, фрагменты в разделителях.

**SEC-21 · Инфо · Мелочи журнала и эксплуатации** - audit без `ip` в `catalog.py:282`, `workflow.py:46-109`; `/api/health` отдаёт число единиц; compose без `read_only`/`cap_drop`.

## B. Проверено, проблем нет

| Область | Почему всё в порядке |
|---|---|
| SQL-инъекции | все запросы параметризованы `?`; динамика только по белым спискам полей(`admin.py:28-63`), `sort` через `order_map`(`search.py:224-230`), экспорт принудительно `published` |
| Доступ к карточке и файлу | сервер проверяет `pub_status` карточки(`catalog.py:88-89`) и `pub_status` + `files.access` файла(`:288-291`); `needs_check` не открывает доступ |
| Утечки неопубликованного | FTS индексирует только published(`search.py:275-294`), фильтры в sitemap, новостях, филиалах, ретривере ИИ; внешнему ИИ - только открытые фрагменты |
| Path traversal | на диске `secrets.token_hex(16)`; при отдаче `Path.name` + `resolve()` + проверка каталога(`catalog.py:294-298`) |
| Тип файла | MIME по сигнатуре байтов, только pdf/jpeg/png/webp/tiff; SVG/HTML/EXE отклоняются; `Content-Disposition: attachment` + `nosniff` |
| CSRF | обязательный заголовок на изменяющих `/api/*` + `SameSite=Lax`; CORS не открыт → чужой origin заголовок не поставит, HTML-форма тоже |
| Сессии | 256-битный токен, в БД sha256; HttpOnly, SameSite, Secure по env; logout удаляет запись; `is_active` на каждом запросе; автовыход 30 мин; фиксация невозможна |
| Пароли | scrypt с солью 16 байт, `hmac.compare_digest`; хеши не отдаются API |
| Роли и workflow | `permissions.can` в каждом хендлере, переходы по `TRANSITIONS` + права целевого статуса; отказы в журнале |
| Журнал | тип операции, объект, результат; `password/token/secret` вырезаются |
| XSS во фронте | данные API через `gosEsc`/`textContent`; markdown сначала экранируется; ответ ИИ экранируется |
| Секреты | ключей в репозитории нет, `backend/data/` в `.gitignore` |
| Инфраструктура | Docker non-root, healthcheck, БД в томе, без `--reload`/debug, `X-Forwarded-For` по умолчанию не доверяется |
| Ошибки | 500 без трассы, `debug` выключен |
