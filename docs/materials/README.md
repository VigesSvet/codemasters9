# Материалы заказчика (Госархив ВКО)

Файлы, которые организаторы Code Masters Hackathon 9.0 разослали капитанам 10–11.11.2026
(переслал Мадияр, @Mako_here). Оригиналы лежат без изменений, переименованы только папки.
Дополнение к ТЗ лежит рядом с основным ТЗ: `docs/tz/ТЗ_дополнения_ГосАрхив_ВКО.docx`
(текстом: `docs/tz/TZ-dopolneniya.txt`). По письму организаторов дополнения рекомендательные,
основное ТЗ не меняется, но их реализация «станет значительным конкурентным преимуществом».

## Что проверить у заказчика

ТЗ запрещает выдавать непроверенные сведения за официальные, поэтому перед публикацией нужно уточнить:

- **Фонды.** В заголовках «по состоянию на 01.01.2026», а сами файлы по именам от 2018 года, газеты до 2017-го. Списка личных фондов нет, хотя дополнение к ТЗ просит выделить их отдельно.
- **Контакты.** `Контакты.docx` расходится со страницей старого сайта http://e-arhiv.vko.gov.kz/ru/Page/Index/1330:
  - режим работы: 8:00–17:00 в docx и 9:00–18:00 на сайте;
  - читальный зал: 9:00–16:00 в docx и 10:00–17:00 на сайте;
  - на сайте есть второй адрес, ул. Крылова, 39, тел. 8 (7232) 25-13-47, со своим читальным залом, в docx его нет.
- **Филиалы.**
  - Почта похожа на опечатку: `b.toleu@alimvko.gov.kz` (вероятно, akimvko) и `v.kozlov@akimvko.qov.kz` (q вместо g).
  - У филиала Маркакөл нет телефона.
  - Координат нет ни у одного филиала.
- **Структура.** Вторая должность заместителя директора не заполнена.
- **Календари.**
  - Есть даты только с месяцем и только с годом, без дня.
  - В русской части 2026 года встречается казахское «18 маусым», в заголовке опечатка «юбилейнных».
  - Английской версии нет.
- **Прейскурант.** Это скан без текстового слоя, поэтому для сайта таблицу нужно распознать и сверить вручную.
- **Пересылка.** Один файл из второй пересылки Telegram не скачал. Состав этого файла неизвестен.
