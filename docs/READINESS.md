## Автоматические проверки

CI (.github/workflows/ci.yml) при каждом push и PR:

- backend: установка зависимостей, ruff check, ruff format --check, pip-audit, pytest -q (142 теста),
  загрузка демо-БД (python -m backend.seed) и smoke-проверка — запуск uvicorn в фоне и
  curl /api/health и /api/catalog/search?q=риддер;
- web: html-validate и scripts/check_links.py web;
- docker: сборка образа (docker build .).

Локально: make test (pytest), make lint (ruff), make check-web (ссылки + html-validate).

## Известные ограничения

- Координаты филиалов не подтверждены: центр населённого пункта или геокодирование
  старого адреса (coords_verified=0).
- HTML новостей со старого сайта переносится без санитизации (выводится как есть).
- Большие страницы publikacii.html и istoriya-kraya.html не разбиты на части.
- Демо-записи каталога помечены is_demo=1 и не выдаются за реальные архивные дела.
- HTTPS — за reverse proxy; внутри приложения COOKIE_SECURE по умолчанию false.
