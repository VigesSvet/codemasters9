# Готовность модулей прототипа (на 12.11.2026)

Таблица по §5 дополнений к ТЗ. Статусы: **Реализовано**, **Частично**, **Имитация/макет**, **Предложено для следующего этапа**.
Прототип статический (`docs/mockups-v2/a-gos/`), сервера и базы пока нет (план P0.3). Поэтому всё, что требует проверки прав на сервере, отмечено как имитация или следующий этап.

| Модуль | Статус | Что есть / что обозначено |
|---|---|---|
| Публичный интерфейс, навигация, хлебные крошки | Реализовано | 30+ страниц, карта сайта |
| Три языка KZ / RU / EN | Частично | Интерфейс на трёх языках; часть контента (позиции прейскуранта, старые документы) только на языке оригинала с пометкой; казахский язык носитель не вычитывал |
| Светлая / тёмная тема | Реализовано | Смена темы и языка не сбрасывает открытую страницу и поисковый запрос |
| Электронный каталог | Имитация/макет | Поиск и фильтры в браузере по тестовым записям; учёт вариантов написания (ё, казахские буквы, старые/новые названия городов); реальные данные фондов — P0.2 |
| Карточка дела / фонда, «материал недоступен» | Имитация/макет | Страница `nedostupno.html`; на сервере выдача закрытого файла не проверяется (P0.3) |
| Состояния 404 / «ничего не найдено» / «недоступно» | Реализовано | `404.html`, пустая выдача каталога, `nedostupno.html` |
| Государственная услуга (справочно) | Реализовано | Порядок получения справки, ссылки на e-vko.gov.kz и egov.kz, отчёты, правила; заявлений на сайте нет |
| Платные услуги (справочно) | Реализовано | Прейскурант по постановлению № 289 от 15.12.2023 таблицей с поиском, PDF рус/каз, примечания и льготы; заказа и оплаты на сайте нет. Таблица перенесена со скана вручную |
| Филиалы и карта | Частично | 13 филиалов по постановлению № 142 и таблице заказчика; координаты приблизительные (центр населённого пункта или геокодирование старого адреса), требуют подтверждения; без карты список и адреса остаются; две почты с вероятными опечатками помечены «уточняется» |
| Об архиве: история, структура, контакты, FAQ | Реализовано | По документам заказчика; часы работы расходятся с прежним сайтом и помечены «уточняется»; FAQ сгруппирован по темам |
| Календарь памятных дат | Реализовано | Перенесён со старого сайта (2010–2026), совпадает с присланными файлами |
| Исторические коллекции, выставки | Частично | Перенесены со старого сайта; вьюер документа — макет |
| ИИ-помощник | Имитация/макет | Заранее подготовленные ответы, помечены «демо-режим» и «ответ сформирован автоматически»; три сценария: есть источник / нет данных / закрытые данные. Настоящая модель — P0.5; внешнему провайдеру уходят только открытые материалы |
| Административная панель | Имитация/макет | Экраны `admin/`; вход, роли, согласование и журнал — P1.10 |
| Права на сервере, раздельные статусы описания и файла, FTS только по разрешённому | Предложено для следующего этапа | Требует backend (P0.3) |
| Роль «администратор филиала» (правит только свой филиал) | Предложено для следующего этапа | P1.10 |
| Версии и согласование (автор, согласующий, дата статуса) | Предложено для следующего этапа | P1.10 |
| Журнал действий (тип операции, ID объекта, результат) | Предложено для следующего этапа | P1.10 |
| Импорт CSV/XLSX с сопоставлением полей и протоколом ошибок | Предложено для следующего этапа | Рекомендательный пункт; входной файл — перечень фондов `.xlsb` со старого сайта |
| Погода, опрос | Имитация/макет | Погода с open-meteo.com; опрос голосует локально |
| Социальные сети | Реализовано | Ссылки на Instagram @arhiv_vko и Facebook vkoarhiv; ленты нет |

Источники тестовых данных: `docs/materials/README.md` (материалы заказчика) и `docs/research/current-site/` (выгрузка старого сайта e-arhiv.vko.gov.kz).
