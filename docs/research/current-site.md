## 3. Боли пользователя
1. Нет HTTPS: https://e-arhiv.vko.gov.kz не отвечает, всё по http (браузеры помечают «небезопасно», формы поиска/гостевой книги открыты).
2. Не адаптивный: фиксированная вёрстка (слайдер 600px, абсолютное позиционирование заголовка 700px, viewport без initial-scale), на телефоне нужен зум.
3. Устаревший дизайн 2010 года (Copyright 2010-2026), баннеры-картинки вместо текста, виджеты погоды Yandex/Gismeteo, счётчики 2000-х.
4. Сломанные разделы: Книга памяти (/DataBases/BaseBooks), «Оставь свой след» (BaseHistMark), Научно-методическая база и Сборники документов отдают HTTP 500; BaseAreas не открывается (таймаут).
5. /kz и /en дают 404; язык переключается ссылкой /kk/Localize/ChangeCulture; английской версии нет. Казахский контент неполон (новости частично на двух языках в одной ленте).
6. Поиск: простая форма POST, результат 640 КБ одной страницей, без фильтров/пагинации/поиска по фондам.
7. Навигация: ~35 пунктов в двух меню, нет иерархии; нужные услуги (справка, запрос) спрятаны в «Государственные услуги» среди законов; нет заметной кнопки «Заказать архивную справку».
8. Филиалы реализованы cookie-переключателем «группы»: ссылка на филиал не шарится, контекст теряется, разделы дублируются.
9. Контакты разбросаны и противоречивы: индекс 070000/070004, нет координат/карты, нет email у Усть-Каменогорского филиала, режим только текстом, телефон «8 (72-340)» нестандартного формата.
10. Контент-свалка: списки фондов и документы — вложения 2018 года без данных в таблицах; структура архива — картинка; архив новостей 590 КБ одной страницей без пагинации.
11. Тестовый мусор в публичной галерее: альбомы «Test Album», «JSON Album», «PUT Album», «CSRF Album»; ссылки с шарингом ведут на developers.facebook.com вместо страницы новости.
12. Нет соцсетей, RSS, подписки, виртуальных выставок, онлайн-заявок; доступность: «версия для слабовидящих» — отдельная страница-инструкция, а не переключатель.

## 4. Технически
- Стек: Microsoft IIS 8.5, ASP.NET MVC 5.2 (X-AspNetMvc-Version), собственная CMS с админкой (/Admin/...), jQuery/jQueryUI, dropzone, ASP.NET unobtrusive. Кириллица в именах файлов /akimsemey/....
- sitemap.xml, robots.txt, RSS (/ru/Rss), API (/api): 404. Публичного API нет.
- Парсинг возможен: серверный HTML, без SPA и авторизации. URL-схема контента: /ru/Page/Index/{id}[/{филиал}]; нумерация сквозная (новости 52794..52814 за 2026). Новости: /ru/Page/ListNewsArchive отдаёт все ~670 за раз (2012-2026). Филиалы: GET /Admin/Group/SetGroup/{id}?url=..&group=..&lang=ru с сохранением cookie. Поиск: POST /ru/Search/FindResult. Вложения лежат в /akimsemey/....
- Лицензионно: контент гос. организации, публичный; для демо хватит ~20 новостей и 4 филиалов; фото брать только с /akimsemey/state/.
