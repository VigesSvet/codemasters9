## 4. Не выгружено / сломано на источнике

- `/ru/DataBases/BaseBooks` (Книга памяти), `BaseHistMark` — HTTP 500 «Время ожидания операции истекло» (SQL timeout на сервере), `BaseAreas` — таймаут соединения. Данных нет, пропущено без возможности обхода.
- Электронный фондовый каталог `BaseEFond`: страница открывается, но дерево рубрик и фондов грузится AJAX-ом (`/ru/DataBases/LoadBaseEFond`, `LoadEFond`) и даёт таймаут. Записей каталога выгрузить не удалось; страница-оболочка сохранена.
- `NamedContent?type=Method|Document`: 500 только при написании `type=Method`/`Document` (регистр!). С `type=method`/`document` страница отдаётся 200, но список пуст (обе ru и kk). Раздел фактически пуст.
- Битые внутренние ссылки: 0 реальных. 109 ответов 404 в манифесте — артефакт обхода (относительные ссылки на страницах `/Page/Index/{id}/{slug}`); все цели существуют по корректному URL. Внешние ссылки на живость не проверялись.
- Полнота kk: обход kk остановлен на лимите ~3000 запросов, не все kk-варианты страниц с суффиксом-группой (`/slug`) выгружены; базовые kk-страницы выгружены для всех ru-страниц.
- Тестовый мусор: альбомы Test/JSON/PUT/CSRF Album (не переносить); у страниц есть кнопка Facebook-share, ведущая на developers.facebook.com.
- Гостевая книга: в итоговом JSON обезличена (автор = «Посетитель», e-mail и телефоны вырезаны). В raw HTML ПДн остаются — не публиковать raw.
