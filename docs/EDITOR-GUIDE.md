# Инструкция редактора

Короткая памятка для сотрудников архива, которые работают с каталогом. Всё действие
происходит в административной части сайта (`/admin`), вход — по логину и паролю,
которые выдаёт администратор.

## Вход

1. Откройте админку и введите логин и пароль.
2. После входа система запомнит вас на 30 минут. Если ничего не делать 30 минут —
   придётся войти заново.
3. После 5 неверных попыток входа подряд вход блокируется на 10 минут.

Роли:

- **editor** — готовит описания, отправляет на проверку, импортирует файлы.
- **moderator** — проверяет, одобряет, публикует, открывает файлы.
- **admin** — полный доступ, управляет пользователями.
- **branch_admin** — администратор своего филиала: правит только карточку своего филиала.

## Создание описания дела

1. Выберите «Создать запись».
2. Заполните обязательные поля: **шифр** (код), **название**, **уровень**
   (фонд / опись / дело / документ), **фонд**, **годы**.
3. Сохраните. Запись появится в статусе **Черновик** — её ещё никто не видит снаружи.

## Отправка на проверку

1. Откройте черновик и нажмите «На проверку» (статус сменится на **На проверке**).
2. Дальше записью занимается **модератор**:
   - может **одобрить** (статус «Одобрено»), затем **опубликовать** («Опубликовано»);
   - может вернуть со статусом **Требует доработки** — тогда вы правьте и снова
     отправляйте на проверку.

Публиковать может только модератор: редактор не может сам выложить запись на сайт —
это защита от ошибок. После публикации запись появляется в поиске для посетителей.

## Доступ к файлу — отдельно от публикации

Важно: **описание** дела и **сам файл** проверяются по отдельности.

- Вы публикуете **описание** — посетитель видит, что дело есть и о чём оно.
- **Файл** (скан/PDF) по умолчанию получает статус **needs_check** («нуждается в проверке»)
  и **не скачивается**, даже если описание опубликовано.
- Открыть файл (статус **public**) может только **модератор** — после того, как убедится,
  что в файле нет персональных данных.

Так архив соблюдает закон: описание доступно всем, а сам документ — только после проверки.

## Загрузка файла

1. Откройте запись и прикрепите файл (PDF или изображение: jpg/png/webp/tiff, до 20 МБ).
2. Файл сохранится со статусом **needs_check**. Пока модератор не откроет его — скачать нельзя.

## Импорт CSV / XLSX

Для массовой загрузки используйте импорт (файл CSV или XLSX). Система сама подскажет,
какие колонки куда лягут; колонки можно поправить вручную перед применением.

Образец колонок — `backend/seed/sample_import.csv`:

| Колонка | Что это |
|---|---|
| шифр | архивный шифр (обязательно) |
| фонд | номер фонда (обязательно) |
| опись | номер описи (можно пусто) |
| дело | номер дела (можно пусто) |
| название | название (обязательно) |
| годы | годы, например 1900-1910 |
| вид документа | тип (org, print, map и т. п.) |
| место | место создания |
| автор | автор |
| ключевые слова | теги для поиска |
| язык | ru / kk / en |

Порядок: сначала **предпросмотр** (система показывает ошибки и дубликаты), затем
**применить**. Все импортированные записи создаются как **черновики** — их нужно
проверить и опубликовать обычным порядком.

## Администратор филиала

Роль `branch_admin` закреплена за своим филиалом: он может править **только карточку
своего филиала** (адрес, телефоны, часы работы, руководителя). Чужой филиал ему недоступен.

## Журнал

Все действия записываются в **журнал** (`audit_log`): кто и когда создал запись, отправил
на проверку, опубликовал, открыл файл, что было отклонено. Просматривать журнал могут
администратор и модератор.
