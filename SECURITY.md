# Политика безопасности

## Как сообщить об уязвимости

- Не публикуйте детали в открытых issue и pull request.
- Сообщите приватно через GitHub: вкладка **Security** -> **Report a vulnerability**
  (GitHub Security Advisory) либо напрямую владельцу репозитория.
- Приложите затронутый адрес или файл, шаги воспроизведения и ожидаемое поведение.

Подтверждаем получение в течение 3 рабочих дней, исправление уязвимости высокой серьёзности -
в течение 14 дней. После исправления находка попадает в таблицу аудита.
